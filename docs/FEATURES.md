## Evidence and verification boundary

The backend `unittest` suite exercises authentication, ownership, document processing/storage behavior, and mocked tutor streams. See [Testing](./TESTING.md) for the current test count and the exact checks actually executed. These checks do not amount to a live browser, upload-format fuzzing, or Gemini-provider verification.
